iOS Shortcut help
  1. Open the free Shortcuts app (it comes with iOS).
  2. Tap + to make a new shortcut and name it Jarvis.
  3. Tap Add Action, search Open App, pick an app (for example Spotify).
  4. Add more Open App actions for each app you want. Shortcuts runs them in order; the last one stays on screen.
  5. Optional: add Speak Text first with “Welcome home, sir.”
  6. Tap Done. Back here, tap Run iOS Shortcut. The first time, iOS asks to allow it.
